Form Edit Button

Odoo opens every form directly in edit mode, so a stray click or keystroke can change a record without anyone noticing. This module brings back the classic behaviour: saved records open read-only, and a clear Edit button unlocks the form only when you mean to change it.
Key Features

Read-Only By Default

Every saved record opens locked, so nobody edits a field by accident.

One Clear Edit Button

A single Edit button unlocks the form. Save and Discard then behave exactly as before.

Works Everywhere

Applies to every form view in the backend. No configuration, no view changes, just install.

How It Behaves

  • Open a saved record: the form is read-only and shows an Edit button
  • Click Edit: the form becomes editable and the Save / Discard controls appear
  • Save or Discard: the form returns to read-only automatically
  • Create a new record: it opens ready to fill in, no extra click needed
